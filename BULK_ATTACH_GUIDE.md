# Bulk Attach Certificate Files - Quick Start Guide

## 🎯 Overview

For users who already entered certification data **before** file attachments were required, this guide shows how to quickly attach all certificate files at once.

## ⚡ Quick Process (5-10 minutes for 50+ certs)

### Step 1: Gather Your Files
- Collect all certificate PDFs/images
- Organize them in a folder
- Supported formats: PDF, JPG, PNG, WEBP
- Max 5MB per file

### Step 2: Go to "Attach Files"
1. Click **"Attach Files"** in the left menu (under DATA section)
2. You'll see statistics:
   - How many certifications need files
   - How many files you've selected

### Step 3: Select Files
1. Click **"CHOOSE FILES"** button
2. Select multiple files at once (Ctrl+Click or Cmd+Click)
3. All selected files appear in the list

### Step 4: Match Files to Certifications
- **Auto-Matching**: System automatically suggests matches based on filename
- **Manual Override**: Click dropdown to select different certification
- **Confirmation**: Green checkmark shows when matched

**Pro Tip:** Name your files like:
- `Coursera-Python-Basics.pdf` → Auto-matches "Python Basics" from Coursera
- `LinkedIn-Excel-Advanced.jpg` → Auto-matches "Excel Advanced" from LinkedIn

### Step 5: Upload All
1. Verify all files are matched (no empty dropdowns)
2. Click **"UPLOAD [X] FILE(S)"** button
3. Watch progress as files upload
4. System automatically syncs data

### Step 6: Verify
- Green checkmark = Success
- Files now linked to certifications
- Data automatically updated in your profile

## 🆘 Troubleshooting

### Files Not Matching Automatically?
- Rename file to match certification name
- Use provider name in filename
- Example: `Udemy-JavaScript-Basics.pdf`

### Upload Failed?
- Check file size (max 5MB)
- Verify file format (PDF, JPG, PNG, WEBP)
- Try uploading fewer files at once
- Check internet connection

### Data Not Syncing?
- Click **"SYNC DATA"** button (top right)
- Wait 2-3 seconds for sync to complete
- Refresh page if needed

## 💡 Best Practices

### Batch Processing
- Upload 10-20 files at a time
- Prevents timeout issues
- Faster matching process

### File Naming
```
Good:
- Coursera-Python-Basics.pdf
- LinkedIn-Excel-Advanced.jpg
- Udemy-Web-Development.png

Avoid:
- cert1.pdf
- file.jpg
- document.png
```

### Organization
1. Create folder: `Certificates to Upload`
2. Sort by provider (Coursera, LinkedIn, Udemy, etc.)
3. Upload by provider batch
4. Verify after each batch
