# Bulk Certificate Attachment - Quick Start

## 🎯 What's New?

Users can now attach 100+ certificate files to existing records **in one go** instead of uploading one at a time.

## ⚡ How to Use (5 minutes)

### Step 1: Go to "Attach Files"
- Click **"Attach Files"** in the left sidebar (under DATA section)

### Step 2: Select Files
- Click **"CHOOSE FILES"**
- Select multiple certificate files (PDF, JPG, PNG, WEBP)
- System shows how many files you selected

### Step 3: Auto-Match
- System automatically matches files to certifications based on filename
- ~90% accuracy - you can manually fix any mismatches
- Green checkmark shows when matched

### Step 4: Upload
- Click **"UPLOAD [X] FILE(S)"**
- Watch real-time progress
- System automatically syncs data when done

### Step 5: Done!
- Files are now attached to certifications
- View them in profiles, categories, or reports

## 💡 Pro Tips

### File Naming
Name your files to match certification names for better auto-matching:
- ✅ `Coursera-Python-Basics.pdf`
- ✅ `LinkedIn-Excel-Advanced.jpg`
- ❌ `cert1.pdf`
- ❌ `file.jpg`

### Batch Processing
- Upload 50-100 files at a time
- Prevents timeout issues
- Faster matching process

### Speed Settings
- **Slow**: 2 concurrent uploads (most stable)
- **Normal**: 3 concurrent uploads (recommended)
- **Fast**: 5 concurrent uploads (fastest)

## 🆘 Troubleshooting

### Files not matching automatically?
→ Rename files to match certification names

### Upload failed?
→ Check file size (max 5MB) and format (PDF, JPG, PNG, WEBP)

### Data not syncing?
→ Click **"SYNC DATA"** button in top right

### Still stuck?
→ Contact administrator
